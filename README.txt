# Subrata Ghosh — Portfolio

A responsive single-page portfolio for a BCA AIML student.

## Customize before publishing
1. Open `index.html`.
2. Replace `your-email@example.com` with your email.
3. Replace the GitHub and LinkedIn URLs with your profiles.
4. You can add a profile image later by placing `profile.jpg` in the folder and adding an `<img>` inside the hero.

## Free publishing with GitHub Pages
1. Create a GitHub account.
2. Create a repository named `subrata-portfolio`.
3. Upload `index.html`, `style.css`, and `script.js`.
4. Open the repository's Settings → Pages.
5. Select the main branch and root folder, then save.
6. GitHub will provide your free `github.io` portfolio address.
